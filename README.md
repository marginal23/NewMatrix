## Описание
В заданной матрице B в каждой строке находятся максимальный и минимальный элементы и меняются местами. При повторяющихся значениях берётся первое в порядке обхода. Исходная и полученная матрицы выводятся в общепринятом виде.

Матрица хранится в обычном двумерном массиве `matrix[20][20]`, фактические размеры — в `rowCount` и `columnCount`. Обмен выполняется через временную переменную.

## Входные данные
- число строк и число столбцов — от 1 до 20
- элементы матрицы — целые числа от -1000 до 1000, вводятся построчно

При неверном вводе программа выводит `INVALID` и завершается.

## Выходные данные
- `Original matrix` — исходная матрица
- `Modified matrix` — матрица, в каждой строке которой максимум и минимум поменяны местами

## Сложность
Копирование матрицы и поиск экстремумов — по одному полному проходу, итого O(rowCount · columnCount).

## Тесты
| Ввод | Ожидаемый результат |
| :-- | :-- |
| `2 3` / `1 5 3` / `7 2 9` | `5 1 3` / `7 9 2` |
| `1 1` / `-5` | `-5` |
| `3 2` / `-4 -9` / `3 3` / `0 -1000` | `-9 -4` / `3 3` / `-1000 0` |
| `1 5` / `2 9 1 9 1` | `2 1 9 9 1` |
| `21 1` | `INVALID` |
| `1 2` / `5 1001` | `INVALID` |

## Как запустить
Создать в Visual Studio консольное приложение C++, добавить в него `NewMatrix.cpp` и запустить без отладки: `Ctrl+F5`.
